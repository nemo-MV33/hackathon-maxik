# norfly — расписание и ДЗ ИРНИТУ в MAX

Чат-бот и мини-приложение в MAX для студентов ИРНИТУ. Трек «Образовательные решения».

- Бот: [max.ru/t692_hakaton_max_bot](https://max.ru/t692_hakaton_max_bot)
- Мини-приложение и API: https://158-160-37-19.sslip.io (открывается кнопкой в чате с ботом)

## Назначение

Студенты 1–2 курса узнают о домашнем задании из общего чата группы, где оно теряется среди сотен сообщений, а расписание смотрят на отдельном сайте. norfly собирает расписание и ДЗ внутри MAX: редактор записывает задание к конкретной паре, а вся группа сразу видит его в боте и мини-приложении.

## Основной пользовательский сценарий

1. Студент открывает бота в MAX и запускает мини-приложение.
2. Находит свою группу поиском (например, `ИСТб-25-1`) и выбирает подгруппу. Выбор запоминается.
3. Видит пары на сегодня: время, аудиторию, преподавателя. Текущая или ближайшая пара подсвечена («Идёт сейчас · ещё 40 мин», «Через 25 мин»). Лента дней недели и режим «Неделя» позволяют листать расписание на весь семестр.
4. Владелец или администратор чата назначает старосту, а староста — одного или нескольких редакторов ДЗ.
5. Редактор выбирает пару из расписания ИРНИТУ и записывает общее ДЗ в чате группы или мини-приложении.
6. Одногруппники сразу видят ДЗ в групповом и личном чате с ботом, а также рядом с парой в мини-приложении.
7. Каждый студент может записать личную версию ДЗ. Она видна только ему и не изменяет общую запись.
8. Если студент опаздывает или не придёт, он нажимает «Опоздаю» или «Не приду» под текущей парой в мини-приложении или в боте (`/absence`) и выбирает причину. Староста получает личное сообщение с именем студента, парой и причиной.

Бот присылает в личный чат уведомления, каждое отключается в профиле мини-приложения или в `/settings`:
- за 15 минут до пары — какая пара и где;
- в 20:00 — сводка на завтра: сколько пар, с какого времени и к каким задано ДЗ;
- когда староста записал или изменил ДЗ;
- при переносах и заменах: отмена пары, новая пара, другая аудитория или преподаватель (проверка раз в 3 часа на неделю вперёд).

Ещё:
- **Староста** после назначения получает в личку инструкцию и кнопки «Записать ДЗ для группы» и «Кто опаздывает сегодня». Под каждым сообщением об опоздании у старосты есть кнопка «Принято» — студент получает подтверждение, а в мини-приложении видит «принято» или «ждёт ответа».
- **Знакомство**: после выбора группы бот и мини-приложение один раз показывают, что умеет norfly, и предлагают включить уведомления (флаг общий).
- **Контрольные**: экзамены и зачёты до конца семестра — плашка над расписанием, отдельный экран и кнопка «Контрольные» в боте; напоминания за 3 дня и накануне.
- **Приглашение**: «Пригласить одногруппников» в профиле, настройках бота и «Управлении» даёт ссылку, по которой новичок сразу попадает в свою группу (`?start=group_478237_1` для бота, `startapp=group_478237_1` для приложения).

Кнопка в уведомлении открывает мини-приложение сразу на нужном дне или паре (параметр `start_param`: `day_2026-10-02`, `lesson_2026-10-02_2_0`).

## Состав и архитектура

```
MAX ── кнопка в чате ── HTTPS-сервер на Yandex Cloud
                          │
                          └── Docker Compose / norfly
                              ├── мини-приложение (React + MAX UI + MAX Bridge)
                              ├── /api/*: профили, общие и личные ДЗ
                              ├── бот (Node.js, long polling)
                              ├── расписание из API ИРНИТУ: семестр раз в неделю,
                              │   ближайшие 2 недели каждые 3 часа
                              └── Docker volumes: ДЗ, профили и выгруженное расписание
```

| Компонент | Путь | Роль |
|---|---|---|
| Мини-приложение | `webapp/` | React 19, `@maxhub/max-ui`, MAX Bridge. Экраны: выбор группы, расписание «День/Неделя» с лентой дней, пара и ДЗ, приём ДЗ по ссылке |
| Выгрузка расписания | `scripts/export-schedule.js` | Забирает группы и расписание: раз в неделю на весь семестр, каждые 3 часа — текущую и следующую неделю. Пишет JSON для мини-приложения |
| Бот | `src/bot/` | Сценарии в чате MAX: расписание, профиль, групповые чаты, ДЗ, сообщения старосте |
| Уведомления | `src/services/notification-service.js`, `src/services/reminder-service.js` | Напоминания о парах, сводка в 20:00, новое ДЗ, переносы и замены |
| Клиент ИРНИТУ | `src/irnitu/`, `src/services/` | Запросы к API, кэш, повторы, нормализация расписания |
| HTTP-сервер | `src/http/` | Раздаёт мини-приложение, `/health`, API расписания, профиля и ДЗ с проверкой подписи `initData` MAX |
| Хранилища | `src/storage/` | JSON-файлы с профилями пользователей и данными групповых чатов |
| Развёртывание | `Dockerfile`, `compose.yaml`, `scripts/docker-start.sh` | Сборка и запуск мини-приложения, API, бота и выгрузки расписания на одном сервере |

Контракт собственного API описан в `openapi.yaml`, а обязательные проверки — в `DATA-API.yaml`.

## Запуск через Docker

```bash
cp .env.example .env   # заполнить BOT_TOKEN и IRNITU_API_TOKEN
docker compose up --build
```

После запуска:
- бот начинает отвечать в MAX;
- мини-приложение открывается в браузере на http://localhost:3000;
- расписание на весь семестр выгружается в течение 15–20 минут после старта, дальше ближайшие 2 недели обновляются каждые 3 часа, а весь семестр — раз в неделю;
- состояние сервиса: http://localhost:3000/health → `{"status":"ok"}`.

Остановка и повторный запуск:

```bash
docker compose down        # остановить, данные сохраняются в томе norfly-data
docker compose up -d       # запустить снова в фоне
docker compose logs -f     # смотреть логи
```

## Работа с данными

- **Расписание** — из API ИРНИТУ, данные реальные. В мини-приложении указано время обновления.
- **Профиль и ДЗ** хранятся на сервере и доступны после проверки подписи `initData` MAX. Общее ДЗ могут менять староста и редакторы; личное — только его владелец.
- **Домашние задания** доступны только через серверный API. Старые ссылки с ДЗ можно открыть и сохранить как личное ДЗ на сервере.
- **Бот** хранит профили и данные групповых чатов в `data/preferences.json` и `data/community.json` (в Docker — том `norfly-data`). Из данных MAX сохраняются только ID пользователя, имя и выбранная группа.
- **Сообщения об опоздании и отсутствии** не анонимные: староста видит имя и ник студента, пару и причину. Они сохраняются в `data/community.json` (`notices`); если староста ещё не открывал бота, сообщение хранится со статусом `pending` и досылается, когда он нажмёт «Начать».
- **Снимки расписания** для поиска переносов лежат в `data/schedule-snapshots.json`: только пары групп на неделю вперёд, без персональных данных.
- **Объявления старосты** хранятся в `data/community.json` (`announcements`) до дня события (или 14 дней без напоминания). Своё время напоминания каждый студент хранит в своём профиле.
- **Удаление аккаунта** (профиль мини-приложения или «Мои данные» в боте) стирает профиль, настройки, личное ДЗ и напоминания и снимает роли старосты и редактора. Сообщения об опозданиях остаются в журнале группы: это запись для старосты, после назначения нового старосты он видит ту же историю.
- Персональные данные несовершеннолетних, телефоны и сведения о здоровье не собираются.
- Время пар везде считается по Иркутску (UTC+8), поэтому у проверяющего из Москвы подсказки «Через N мин» совпадают с иркутскими.

## Пошаговый сценарий проверки

1. Откройте [бота](https://max.ru/t692_hakaton_max_bot) в MAX и нажмите кнопку открытия мини-приложения.
2. Введите `истб 25` и выберите **ИСТб-25-1** → **вся группа**.
   *Ожидается:* вкладка «Главная»: пары на сегодня или, если сегодня пар больше нет, ближайшая пара с подзаголовком «Завтра» / «Послезавтра»; ниже «Задачи» — ДЗ и объявления от ближайшего к дальнему.
3. Вкладка «Расписание»: переключите «День / Неделя», полистайте недели. Нажмите лупу, введите `Лукьянов`, фильтр «Преподаватели», откройте результат.
   *Ожидается:* расписание преподавателя по неделям, у пар видны группы.
4. Вкладка «Планер» → «+ ДЗ»: выберите день, пару, напишите задание, напоминание «В день пары в 8:00», сохраните.
   *Ожидается:* задача в дне планера и на «Главной»; в назначенное время бот присылает напоминание.
5. Добавьте бота в чат учебной группы и сделайте администратором. Администратор нажимает «Настроить» и выбирает группу, затем пишет `/headman` и выбирает старосту из списка участников. Староста пишет `/editor` и выбирает редактора.
   *Ожидается:* `/team` показывает старосту и редакторов; повторный выбор редактора снимает права.
6. Староста в мини-приложении открывает вкладку «Староста» → «Объявления», пишет текст, ставит напоминание и публикует.
   *Ожидается:* объявление в чате группы и в личке у каждого; студент открывает его на «Главной» и меняет время напоминания только для себя.
7. Студент на «Главной» под текущей парой нажимает «Опоздаю», выбирает «10 мин» и причину.
   *Ожидается:* «Отправили старосте»; у старосты в боте сообщение «Опоздание · ~10 мин» с кнопкой «Принято», во вкладке «Староста» — строка в списке дня и минуты в «Досье группы».
8. Староста сам нажимает «Опоздаю».
   *Ожидается:* бот и приложение просят выбрать одногруппника, которому доверено получать опоздания старосты; сообщение уходит ему.
9. Профиль (аватар справа вверху) → «Уведомления»: поменяйте «за сколько минут до пары» и время сводки; «Дисциплины» → предмет → форма контроля «Экзамен»; «Тема» → «Тёмная».
   *Ожидается:* настройки сохраняются и видны в боте (`/settings`); тема меняется сразу.
10. Профиль → «Удалить аккаунт» → «Да, удалить».
   *Ожидается:* приложение возвращается к выбору группы, бот больше ничего не присылает; сообщения об опозданиях этого студента остаются у старосты.

Карта всех сообщений и кнопок бота с чек-листом для ручной проверки: [norfly — карта бота](https://claude.ai/artifact/StmnHzcVoUprZyr8Upi1Br).

Локальная проверка через Docker: после `docker compose up --build` откройте http://localhost:3000 и пройдите шаги 2–3 в браузере. Вне MAX кнопка «Назад» клиента заменяется кнопкой на экране, а ДЗ недоступно: сервер принимает только подписанные MAX запросы.

## Мини-приложение

Внизу три вкладки: **Главная** (ближайшие пары и задачи), **Расписание** (день и неделя, поиск по преподавателям, аудиториям и группам), **Планер** (задачи по дням, создание ДЗ с напоминанием). У старосты есть четвёртая вкладка **Староста**: кто опаздывает сегодня и вчера, «досье» по каждому студенту (опоздание считается по минутам, пропуск — как пара, 90 минут) и объявления.

Профиль открывается аватаром в правом верхнем углу:
- **Университет** — группа и подгруппа, здесь же их смена;
- **Дисциплины** — предметы группы за семестр с полными ФИО преподавателей из ИРНИТУ и формой контроля, которую студент отмечает сам; при смене группы список заменяется;
- **Опоздания** — предупредить о конкретной паре, история своих сообщений; у старосты — доверенный одногруппник и досье группы;
- **Уведомления** — общий выключатель, за сколько минут до начала и до конца пары, время сводки, ДЗ, объявления, переносы, контрольные;
- **Язык** и **Тема** (светлая, тёмная, как на устройстве);
- **Мои данные**, **Пригласить одногруппников**, **Вопросы и ответы**, **Удалить аккаунт**.

Номер пары везде порядковый в дне студента: если первая пара начинается в 13:45, это «1 пара». Официальное время показано рядом.

## Меню бота

Всё, что умеет бот, доступно кнопками — команды вводить не обязательно.

**Личный чат** (`/start`): «Сегодня / Завтра / Неделя», «Домашка», «Ещё» и кнопка приложения. В «Ещё»: «Опоздаю / не приду», «Контрольные», «Объявления», «ДЗ себе», «Найти», «Настройки»; у старосты ещё «Кто опаздывает» и «Объявление», у редактора — «Записать ДЗ для группы». В настройках — группа, уведомления (время до пары, время сводки, общий выключатель), язык и «Мои данные» с удалением аккаунта.

**Чат группы** (`/start` или `/help`): «Сегодня / Завтра / Неделя», «Домашка» и «Ещё» («Записать ДЗ», «Кто записывает ДЗ», «Управление»). В «Управлении» администратор чата привязывает группу, назначает старосту из списка участников и меняет язык, а староста выбирает редакторов ДЗ из того же списка. Если нажать кнопку без нужных прав, бот покажет короткое уведомление и ничего не изменит.

Расписание в боте: день начинается с «📅 Завтра, 28 сентября · 3 пары», у каждой пары порядковый номер 1️⃣ 2️⃣, значок типа (📖 лекция, ✏️ практика, 🧪 лабораторная, 🎯 экзамен, ✅ зачёт), 📍 аудитория и 👤 преподаватель. В недельном виде дни разделены линией.

## Команды бота

Команды работают и в виде `/today@t692_hakaton_max_bot`, и с аргументами (`/find Иванов`, `/setup ИСТб-25-1`). В личном чате можно не пользоваться командами: любое сообщение — поиск группы, преподавателя или аудитории.

| Команда | Где | Что делает |
|---|---|---|
| `/start` | везде | Меню; при первом запуске — выбор языка |
| `/today`, `/tomorrow`, `/week` | везде | Расписание своей группы или группы чата |
| `/homework` | везде | ДЗ на ближайшие пары |
| `/add` | везде | В группе — общее ДЗ (староста и редакторы), в личке — своя версия |
| `/news` | личный чат | Объявления старосты и своё время напоминания |
| `/absence` | личный чат | Предупредить старосту: на сколько опоздаешь и почему; староста — доверенному одногруппнику |
| `/find` | личный чат | Поиск группы, преподавателя, аудитории |
| `/settings` | личный чат | Группа, уведомления, язык, мои данные, удаление аккаунта |
| `/setup` | группа, админы | Привязать чат к учебной группе |
| `/manage` | группа | Управление: староста, редакторы, доступ, язык |
| `/headman`, `/editor` | группа | Выбор из списка участников: назначить старосту, дать или снять права на ДЗ |
| `/team`, `/access` | группа | Кто записывает ДЗ; кто может его записывать |
| `/language` | везде | Переключить язык (в группе — для всего чата, только админы) |
| `/help` | везде | Список команд |

Старые команды (`/schedule`, `/profile`, `/homework_create`, `/homework_personal`, `/homework_team`, `/homework_access`) продолжают работать.

## Языки

Бот и мини-приложение работают на русском и английском. Язык выбирается при первом `/start` и хранится в профиле, поэтому бот и приложение показывают один и тот же язык; переключить можно в `/settings` или переключателем RU/EN на экране выбора группы. Названия предметов, ФИО и аудитории приходят из ИРНИТУ и не переводятся, типы занятий переводятся. Поиск группы понимает латиницу: `istb-25-1` находит «ИСТб-25-1».

## Разработка

```bash
npm ci && npm ci --prefix webapp
npm test                 # тесты сервера и сценарии бота
npm run dev:web          # мини-приложение на http://localhost:5173 с демо-данными
NORFLY_API=http://localhost:3001 npm run dev:web  # то же, но с настоящим API и расписанием на порту 3001
npm start                # бот и HTTP-сервер (нужен .env)
npm run export:schedule  # выгрузить ближайшие недели в webapp/dist/data (EXPORT_MODE=full — весь семестр)
```

## Известные ограничения

- Мини-приложение и API должны быть доступны через один публичный HTTPS-адрес, указанный в `MINI_APP_URL`.
- В MVP текст одного ДЗ ограничен 2000 символами; файлы и фото к ДЗ пока не прикрепляются.
- Ближайшие 2 недели обновляются раз в 3 часа, остальные недели семестра — раз в неделю. Изменения в дальних неделях появляются с задержкой до недели.
- Бот работает, пока запущен процесс с его токеном; одновременно должен работать только один экземпляр.
- Адрес мини-приложения, который открывает кнопка MAX, задаётся владельцем бота на платформе MAX для партнёров; через Bot API его поменять нельзя.
- Фото справки к сообщению старосте можно приложить только в боте; из мини-приложения отправляется текст.
- Переносы и замены проверяются раз в 3 часа, поэтому уведомление может прийти с задержкой до 3 часов после изменения в ИРНИТУ.
- Состояние ввода в боте (текст ДЗ, причина отсутствия, текст объявления) хранится в памяти процесса: после перезапуска начатый ввод нужно повторить. Кнопки при этом продолжают работать.
- В чате группы клиент MAX показывает команды из списка «/» с префиксом имени бота (`@t692_hakaton_max_bot/start`). Это поведение клиента, из Bot API оно не настраивается.
- Формы контроля по дисциплинам ИРНИТУ заранее не публикует, поэтому студент отмечает их сам.
- Минуты опоздания указывает сам студент; пропуск целой пары в «досье» считается как 90 минут.
